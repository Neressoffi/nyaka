v4 — Espace d'administration local (Decap CMS) (3 novembre 2026)
--------------------------------------------------------------------------------
  OBJECTIF
    Modifier soi-même tous les textes, projets et images du site, sans toucher
    au code. Mode d'emploi : ADMIN-MODE-D-EMPLOI.txt (à la racine de magic).

  UTILISATION
    npm install        (une seule fois)
    npm run admin      puis ouvrir http://localhost:3000/admin

  AJOUTÉ
    content/pages/accueil.json      Page d'accueil (toutes les sections)
    content/pages/*.json            Textes des autres pages + en-tête, pied de page
    content/donnees/*.json          Pôles, projets, situations, approche, à propos, menu
    public/admin/index.html         Page d'administration
    public/admin/config.yml         Réglages de l'administration
    ADMIN-MODE-D-EMPLOI.txt

  MODIFIÉ
    Les composants et fichiers lib/*-data.ts lisent désormais leurs textes
    dans le dossier content/ au lieu de les contenir en dur.
    next.config.mjs : /admin redirige vers l'administration.
    package.json / package-lock.json : scripts « admin » et « cms »,
    outils concurrently et decap-server.

  VÉRIFICATION
    Les 8 pages du site affichent exactement les mêmes textes, images et liens
    qu'en v3 (comparaison automatique page par page).

  RESTAURER LA VERSION D'AVANT (v3)
    Copier chaque fichier de « v4/avant » à son emplacement d'origine
    (les « __ » du nom correspondent aux dossiers, ex.
    components__Hero.tsx.txt -> components/Hero.tsx) et retirer « .txt ».
    Les dossiers content/ et public/admin/ peuvent alors être supprimés.
